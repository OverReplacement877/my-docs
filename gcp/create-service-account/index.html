    Create a Service Account in Google Cloud

    Prerequisites

    • Google Cloud project
    • Owner or Editor access

    Steps

    1. Log in to Google Cloud Console
    2. Select your project, go to top left burger icon, If you have no project yet, create a project and name it, refer on the second image below for creating and selecting project(e.g. cctv watch)






    3. Open ☰ → IAM & Admin → Service Accounts





    4. Click Create Service Account

    5. Enter and fill-up the following fields:

    6. Name (e.g. my-service-account)
    7. Description (optional)
    8. Click Create and Continue
    9. Assign required Role(s) (use least privilege, choose editor for simplicity)
    10. Click Continue → Done

    Create a Key

    1. Click the service account
    2. Go to Keys → Add Key → Create new key
    3. Select JSON
    4. Click Create (key downloads automatically)
